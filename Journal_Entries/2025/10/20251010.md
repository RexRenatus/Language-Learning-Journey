- **Mandarin Flashcard Generation - Multiple Choice Systems**

    - Created two flashcard formats for comprehensive character learning

    - **Format 1: Character → Pinyin Selection (Tone Practice)**
        - Script: `add_flashcard_choices.py`
        - 1,927 characters processed
        - Each flashcard has 5 tone choices: Tone1, Tone2, Tone3, Tone4, Neutral
        - Output: `consolidated_characters_flashcards.csv`
        - Column format: Order Number | Item | Pinyin | Frequency | Choice_Tone1-4 | Choice_Neutral | Correct_Answer

    - **Format 2: Pinyin → Character Selection (Recognition Practice)**
        - Script: `create_reverse_flashcards.py`
        - 1,927 reverse flashcards generated
        - Each flashcard has 5 character choices (A-E)
        - Mathematically randomized distractors (prime-based formulas)
        - No patterns: Answer distribution verified balanced
        - Output: `reverse_flashcards_pinyin_to_character.csv`
        - Column format: Order Number | Pinyin | Correct_Character | Frequency | Choice_A-E | Correct_Choice
        - Use case: See pinyin (yi1), choose correct character from (长, 魔, 一, 来, 克)

    - **Answer Distribution Analysis (Reverse Flashcards):**
        - Choice A: 374 (19.41%)
        - Choice B: 355 (18.42%)
        - Choice C: 446 (23.14%)
        - Choice D: 361 (18.73%)
        - Choice E: 391 (20.29%)
        - Well-balanced - no position bias detected

    - **Mathematical Randomization Strategy:**
        - Prime number multipliers (7, 11, 17, 23, 31, 37, 41, 43)
        - Prime offsets (13, 29, 53, 97, 127, 157, 191, 223)
        - Ensures no patterns emerge during sequential study
        - Reproducible: same character always gets same distractors
        - Position shuffle using seed: `(index * 31 + 41)`
